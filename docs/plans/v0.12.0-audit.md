### Findings

#### A-01 — Start (SCR-02): *Aufguss starten* overlaps the header picture (PO point, D-138 Q11, item 18)
- **Problem:** the picture and the card sit apart (the band's 8 dp bottom padding, then the card), so they read as two things and the block takes 256 dp under the title bar before *Zuletzt aufgegossen*.
- **Proposal:** the picture keeps its 120 dp band; the first card of the block (*Aufguss starten*, or *Aufguss fortsetzen* in the active state, with the cards below it) is pulled up so it overlaps the picture's visible lower edge, and everything below moves up by the same amount (a layout modifier that places the card column at −(8 + overlap) dp and reports its height shorter by as much; drawn after the picture, so on top). Two values to pick from, fixed dp (not scaled with font, so the picture stays visible at font 2.0):
  - **variant a:** overlap **24 dp** ≈ one third of the card's 72 dp → the block moves up 32 dp;
  - **variant b:** overlap **36 dp** ≈ one half → the block moves up 44 dp; the card then covers the lower blossoms.
  - Net effect with A-02's taller card (72 dp instead of the 48 dp text button, plus the 12 dp gap): *Zuletzt aufgegossen* starts 12 dp higher than today in a, 24 dp higher in b (at font 1.0, light).
  - **Gap between the cards: 12 dp** (`UmamiSpacing.Small`), the gap *Aufguss fortsetzen* → *Aufguss starten* already uses; the same 12 dp to the *Schnelltimer* card (A-02). The section header below keeps its 24 dp top padding. Reliability banner stays above the picture, the nudge card below the cards (item 18). Empty state: no picture, so no overlap (A-02 picture). No shadow (flat design, 03 §3.3).
- **Kind:** component/layout
- **Pictures:** A-01_before.png / A-01a_after.png / A-01b_after.png; `_font2` and `_dark` of each (A-01_before_font2.png, A-01a_after_font2.png, A-01b_after_font2.png, A-01_before_dark.png, A-01a_after_dark.png, A-01b_after_dark.png); active session, variant a: A-01a_active_before.png / A-01a_active_after.png. **All after pictures already contain the A-02 card**: the PO judges the block as a whole.
- **Modules/files:** `feature/home/.../HomeScreen.kt` (`BrewCards`, `Header`)  **Tier:** T2  **Timer code:** no
- **Depends on / conflicts with:** rendered together with A-02 (the PO's pick of a or b sets the value in 03 SCR-02)

#### A-02 — Start (SCR-02): *Schnelltimer* as a second, lighter card (PO point, D-138 Q12, item 17)
- **Problem:** *Schnelltimer* is a small text button that leaves an odd 56 dp of air below it and looks like an afterthought next to the card.
- **Proposal:** a full-width card under *Aufguss starten*, the same shape and size: `Surface` with `UmamiShape.PrimaryCard` (12 dp), `colorScheme.surface`, a 1 dp `outline` border (`UmamiSpacing.Hairline`), min height 72 dp, padding 24 dp × 16 dp; the clock icon (`UmamiIcons.Timer`) 32 dp in `primary`; title *Schnelltimer* in `titleLarge` `onSurface`; second line „Nur die Zeit, ohne Tee" / „Just the time, no tea" in `bodyMedium` `onSurfaceVariant`; a plain chevron in `onSurfaceVariant` (no fill). One button for TalkBack (Surface onClick merges). Same `press` scale as `PrimaryActionCard` (0.97, `tween(120, CalmEaseOut)`, release spring) — not visible in a still. 12 dp below the card above it; at font 2.0 both cards grow and stay stacked (A-01a_after_font2.png). In the empty state the card takes the text button's place under the title bar (8 dp top). „Accent colour" for the icon is read as `primary` (#4A5643 light / #B9C8A6 dark): the warm accent #D9A35F would be 1.97:1 on `surface`, below 3:1 for a graphic.
- **Kind:** component/layout
- **Pictures:** in A-01a/A-01b after pictures (light, dark, font 2.0); English: A-02_en_before.png / A-02_en_after.png; empty state: A-02_empty_before.png / A-02_empty_after.png
- **Modules/files:** `feature/home/.../HomeScreen.kt` (replaces `QuickTimerEntry`), `feature/home/src/main/res/values{,-en}/strings.xml` (`home_quick_timer_subtitle`, approved copy)  **Tier:** T2  **Timer code:** no
- **Depends on / conflicts with:** A-01 (one block)

*Note:* findings A-03…A-06 are independent of each other and of A-01/A-02; each after picture was rendered with only its own change on.

#### A-03 — Neue Session (SCR-04): the selected recipe chip in `primaryContainer`, as 03 §3.1 says
- **Problem:** the selected recipe chip uses M3's default `secondaryContainer`, against 03 §3.1, which assigns `primaryContainer` to selected chips. In dark the cream (#E5DFCF) chip is the brightest thing on the screen and competes with the cream *Session starten* pill; in light the cream reads as a neutral tag rather than a choice.
- **Proposal:** `FilterChipDefaults.filterChipColors(selectedContainerColor = primaryContainer, selectedLabelColor = onPrimaryContainer, selectedLeadingIconColor = onPrimaryContainer)` on the recipe chips (and *Ohne Rezept*). Light: sage #DDE2D2 with ink (a hue shift towards the matcha accent; the fill stays as light as before, the ✓ still carries the state); dark: the generated deep green #2B4F1E with a light-green label, which no longer outshines the start pill. The dark green is noticeably more saturated than the rest of the Steeping palette: the PO should judge the dark picture in particular. No new token. The same default is used by every `FilterChip` in the app (Sammlung, Katalog, Journal filters, Schnelltimer chips): merge with the other groups' chip findings if they make one; this render shows the setup only.
- **Kind:** type/colour
- **Pictures:** A-03_before.png / A-03_after.png; A-03_before_dark.png / A-03_after_dark.png
- **Modules/files:** `feature/brew/.../setup/BrewSetupScreen.kt` (`RecipeChips`)  **Tier:** T3 (feature:brew)  **Timer code:** yes
- **Depends on / conflicts with:** —

#### A-04 — Neue Session (SCR-04): one right edge for the form
- **Problem:** the right-hand column stops at five different places: the switch at 20 dp from the edge, the vessel chevron ≈ 24 dp, the + glyph ≈ 27 dp, *Bearb.* ≈ 25 dp, the step temperatures ≈ 30 dp (left-aligned in their 48 dp column); the column looks ragged against the straight left edge.
- **Proposal:** align everything on the 20 dp side margin: `AmountRow` end padding 12 → 8 dp (the − / + `IconButton`'s 24 dp icon box then ends at 20 dp, touch target unchanged at 48 dp); the step temperature `textAlign = End` in its `widthIn(min = 48.dp)` column (numbers right-aligned, `tnum` already on); the *Bearb.* `TextButton` end padding 12 → 8 dp. Durations follow (they sit at a fixed 16 dp before the temperature column).
- **Kind:** spacing
- **Pictures:** A-04_before.png / A-04_after.png
- **Modules/files:** `feature/brew/.../setup/BrewSetupScreen.kt` (`AmountRow`), `.../setup/BrewSetupParts.kt` (`StepsSection`)  **Tier:** T3 (feature:brew)  **Timer code:** yes
- **Depends on / conflicts with:** —

#### A-05 — Neue Session (SCR-04): the tea name hugs the top bar
- **Problem:** the headline tea name starts 8 dp under the top bar (whose surface is a shade lighter), so it reads as squeezed against it, while the gaps further down are 24–32 dp.
- **Proposal:** `TeaHeader` top padding 8 → 16 dp (`UmamiSpacing.Medium`); bottom stays 8 dp. Everything below moves down 8 dp; *Session starten* stays on screen at font 1.0 and 2.0.
- **Kind:** spacing
- **Pictures:** A-05_before.png / A-05_after.png; A-05_before_font2.png / A-05_after_font2.png
- **Modules/files:** `feature/brew/.../setup/BrewSetupScreen.kt` (`TeaHeader`)  **Tier:** T3 (feature:brew)  **Timer code:** yes
- **Depends on / conflicts with:** —

#### A-06 — Teeauswahl (SCR-03): the search field like every other search field
- **Problem:** the picker's search is the only search field with a floating label and no magnifier; Sammlung, Katalog, Journal, Sorte wählen and the descriptor sheet all show a leading search icon with a placeholder.
- **Proposal:** `OutlinedTextField` with `placeholder = „Suchen"` (same string) and `leadingIcon = UmamiIcons.Search` instead of `label`; padding unchanged. Without the floating label's top inset the field is 8 dp shorter, so in the picture the sheet sits 8 dp lower; nothing else moves.
- **Kind:** component/layout
- **Pictures:** A-06_before.png / A-06_after.png
- **Modules/files:** `feature/brew/.../picker/TeaPickerSheet.kt` (`PickerContent`)  **Tier:** T3 (feature:brew)  **Timer code:** yes
- **Depends on / conflicts with:** —
