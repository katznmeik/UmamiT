## 2. Lint `UnusedResources` and `UnusedIds`

Method: both checks set to `warning` in a local copy of `config/lint/lint.xml`, and `checkDependencies = true` in a local copy of `Quality.kt` (the project sets it `false`, and lint does not report unused resources of a library module alone). `./gradlew :app:lintDebug` then analyses the app and every module together. Both edits reverted.

| Check | Result |
|---|---|
| `UnusedResources` | **0** in `app` and in all 24 library modules |
| `UnusedIds` | **0** |

Sanity check: an unused string added to `core:designsystem` was reported (`R.string.zz_probe_unused appears to be unused`) and then removed, so the run does see library resources. The plain per-module `./gradlew lint` with the two checks on (checkDependencies off, as in CI) also reports 0. Consequence: **no strings or resources to delete** from this tool; `strings.xml` can only lose entries that go with deleted code (plan „Proof" 6).
