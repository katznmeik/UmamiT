### Order

At most 2 implementers at a time, each in its own worktree, and **one Gradle build at a time**. The pairs are chosen so that two running tickets do not edit the same files:

| Wave | Tickets | Why together |
|---|---|---|
| 1 | #222 ‖ #223 | Vocabulary and data layer; no shared files. |
| 2 | #224 ‖ #231 | Session page and journal list. |
| 3 | #225 ‖ #227 | Session page and the sheet. |
| 4 | #226 ‖ #230 | A new section and the editor; both touch `SessionPageScreen.kt` lightly (a section, the ⋮), merge #226 first. |
| 5 | #228 ‖ #232 | `feature:journal` + `core:domain` and `feature:collection`. |
| 6 | #229 | Alone: it moves pager code out of the tea detail that #232 edits. |

- **Goldens:** each ticket records only its own module's goldens. A full `recordRoborazziDebug` is not needed; `verifyRoborazziDebug` on the merged branch after each wave.
- **Sessions:** the build phase will not fit one session. A session that stops part-way writes `docs/plans/v0.6.0-resume.md` (what is merged, what runs, what is next) and the next-session prompt.
- **Environment:** Maven Central rate limits (HTTP 429): retry Gradle with a pause of about 90 s. A fresh container needs the Robolectric SDK 35 jar fetched first (`v0.4.0-resume.md` §3).

## Verification (orchestrator, per ticket)

`./gradlew spotlessCheck detekt lint testDebugUnitTest`, `verifyRoborazziDebug`, `checkManifestPermissions`, and the diff, before merging a result into the PR branch. A subagent's report is not proof. For #223 also `scripts/check-frozen-schemas.sh` and `git diff --exit-code core/database/schemas` after the build; `assembleDebugAndroidTest` once per wave.

Per ticket, check in the diff:
- no file under `core/timer`, `core/timer-engine`, the timer screens or the app's timer wiring changed (if one did: stop, the milestone then needs the T4 timer review and the accuracy variants per rc, 09 §4a);
- session completion (`CompleteSession`) is unchanged;
- every UI string is in `strings.xml`, German, informal;
- screenshot tests use placeholder images only (D-016).
