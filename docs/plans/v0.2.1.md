## Process (as in M1 and M2)

- **PR:** one PR from `claude/umamit-m1-start-k0jg3n` into `main`, a draft while tickets are open, using `.github/pull_request_template.md`.
  - GitHub deletes the branch after each merge, so recreate it from `main` before the first commit.
- **Implementers:** subagents in worktrees (`isolation: "worktree"`). Set `model` and `effort` per tier (CLAUDE.md rule 5).
  - Brief them with pointers (ticket, spec sections, D-093), not copies.
  - Escalate one tier after a failure.
- **Before merging a ticket:** verify it yourself on the combined tree with the gate below and read the diff. A subagent's report is not proof.
- **Bookkeeping:** tick the ticket's checkboxes, close the ticket with the PR, update `PROJECT_STATE.md`.
- **Decisions made while building:** record them as D-095 and up, with a change-log row.
- **Code review at the end:** T4 for the timer and migration areas; fix or answer every finding.
- **Reporting:** push notifications only when the PO must act (rc ready, a blocking question). Questions go to the PO as selectable options.

## Local gate

The CI gate in sequential parts; the Gradle daemon is killed for memory when everything runs at once.

```bash
export ANDROID_HOME=${ANDROID_HOME:-/opt/android-sdk}
./gradlew spotlessCheck detekt checkManifestPermissions
./gradlew --max-workers=1 testDebugUnitTest
./gradlew --max-workers=1 lint
./gradlew --max-workers=1 verifyRoborazziDebug
./gradlew assembleDebugAndroidTest
```

- **A part killed for memory** (daemon OOM, exit 137) is not a test failure; rerun that part alone.
- **Maven Central HTTP 429:** rerun.
- **Instrumented tests** run only in CI's emulator job (no KVM here).
- **Goldens:** re-record with `recordRoborazziDebug` and look at every changed golden before committing it.

## Guards that bite in this release

- **Frozen schemas:**
  - `umamit.db` v1 and `catalog.db` v1 are frozen by the `v*` tags.
  - #90 adds schema 2 next to schema 1, never editing it; `scripts/check-frozen-schemas.sh` and CI's schema-freshness check must stay green.
  - The script compares bytes (#58 D-O2), so don't let a Room upgrade reformat old schema files.
- **Accuracy run:**
  - Timer code changes, so every rc needs a PASS of `accuracy.yml` on its commit: full SHA, `api-level` 36, `steps` 50, `inject-delay-ms` 0. It takes about 1 h.
  - Target: p95 ≤ 250 ms and max ≤ 1000 ms for pre-alert and alert.
  - rc.1 of M2 failed once on a cold first pre-alert (1178 ms); D-092 fixed it by loading sounds ahead. Keep that true for the new sounds in #84.
- **Timer tests:** the 04 §12 tests must pass on every timer change (rule 8).
- **Possibly timing-sensitive tests under load**, seen once: `CatalogRefresherTest.eachStopKeepsTheOldCatalog`, `ExactPricesTest.onlineTheSizesPageGivesTheExactPrice`. If they flake, make them clock-independent; never skip them.
- **No downgrades:** going back to v0.2.0 needs an uninstall (D-093 Q16). Never use a destructive migration.
