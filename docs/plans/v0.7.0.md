## Verification (orchestrator, per ticket; proposed to the PO, as agreed for v0.6.1)

1. The orchestrator reads the diff itself (including the empty timer/schema diff above).
2. Locally: the touched modules' scoped checks where the implementer's report leaves doubt (`:core:domain:test` for #256), and the cross-module check `spotlessCheck :app:assembleDebug :app:assembleDebugAndroidTest :app:compileDebugUnitTestKotlin`.
3. Push; **CI on the milestone PR is the full gate** (including the emulator jobs). The orchestrator checks its result before the next merge builds on that head and fixes red at once.
4. The full local gate runs once more on the rc commit (#263), with the reviews.

A subagent's report is not proof.
