## 3. Known points from the build (for the reviewers)

- **#183 memory:** `RoomTeaPhotos.read` buffers a picked file of up to 128 MB in memory, plus the `toByteArray` copy,
  and an `OutOfMemoryError` is not caught. The timer runs in the same process (rule 8). Consider a stream decode or a
  lower cap.
- **#183:** the setup (SCR-04) and the session page (SCR-16) show no tea photo today, so the cover isn't shown there
  (02 TEA-05 notes it). The spec's "everywhere a tea photo shows today" means no change.
- **#180:** the saved-sheet request still carries only the session id; the sheet asks
  `SessionRepository.openedDateChange`. Undo offered once; a date changed since is left alone.
- **#178:** a passed best-before date gives *Über dem Höhepunkt* even for a style without a window; the best-before
  day itself is still good; no midnight ticker (the label follows the next data change). The detail's new FRISCHE
  section shows „Geöffnet am …" and DETAILS (#179) shows the opening date too: shown twice (design review).
- **#187:** an unreadable vessel photo at *Speichern* is skipped silently (the tea photo shows a toast); the picker's
  grant may be gone after a process death between pick and save.
- **#181:** a catalog tea gets the simple purchase sheet plus the reorder link; the shop-size flow (SCR-21/23) stays in
  the Katalog tab. The sheet has its own date field, close to the tea editor's `PurchaseDate`.
- **#185:** VORRAT shows the newest 5 history rows, then *Alle N Einträge anzeigen*. A detail opened above the setup
  (⋮ *Tee ansehen*) has no session route, so brew rows are not tappable there (in SCR-29). The edit FAB can cover a
  row's delete icon at the bottom edge (88 dp end space keeps it reachable).
- **#184:** catalog recipe = `source != USER`; old catalog recipe ids are reused (the active brew's recipe id goes to
  the new catalog default) so a running session's recipe link survives; but *Im Rezept speichern* after that session
  then writes into the new default catalog recipe. No success message after a reset.
- **#182:** a priced session with every step skipped counts as one cup; a rinse-only recipe gives no estimate.
- **CI:** green on the build tip `4063c488` (all four jobs); the local full gate passed on it too.
