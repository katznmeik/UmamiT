## Risk rules

- **Timer path untouched (D-137 items 23–24):** no ticket edits
  `feature/brew`, `core/timer` or `core/timer-engine`; every ticket's
  acceptance criteria include an empty `git diff` there. Hence no T4 timer
  review. The final still needs all three accuracy variants (09 §4a).
- **No data change:** umamit.db stays v9, no new settings key, no new
  permission; `checkManifestPermissions` and `check-frozen-schemas.sh`
  unchanged; `core:backup` untouched.
- **Copy is approved text:** the implementers use 03's copy word for word in
  both languages. A wording problem found in the build goes into a D-137
  build note and back to the PO, it is not rewritten silently.
- **Public repository (rule 3):** mock-ups and goldens use only the invented
  demo data of 03 SCR-36 and the type leaf; no shop text, name or photo.
- **Module graph unchanged (06 §3):** everything new sits in
  `feature:onboarding`; other features only gain a ⋮ item and a callback.
- **Detekt limits:** `MainActivity` and `UmamitRoot` sit at their limits
  (PROJECT_STATE „Combined check"); the new routes go in a separate nav
  helper, not into `UmamitRoot`'s body.
