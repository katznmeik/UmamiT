## Risk rules

- **Timer path (D-138 Q6, item 20):** the timer screens may change visually
  only if the PO picks such a finding. A ticket that edits `feature/brew`,
  `core/timer` or `core/timer-engine` is T3 or higher, needs the 04 §12
  tests, and makes v0.12.0 a timer-code release: the T4 timer review and
  all three accuracy variants before every rc and the final (09 §4a).
  Every other ticket's acceptance criteria include an empty `git diff`
  there. The triage records which case holds.
- **No behaviour or data change:** umamit.db stays v9, no new settings key,
  permission or network use; `checkManifestPermissions` and
  `check-frozen-schemas.sh` unchanged. A finding that needs one is out of
  scope.
- **Proposal code is throwaway (item 21):** the audit's renders come from a
  local worktree that is never pushed; only pictures are committed
  (`docs/design/review/v0.12.0/audit/`), with demo data and the app's own
  illustrations only (rule 3).
- **Nothing is picked for the PO:** except the edge-rule breaches (Q13),
  no audit finding is built without the PO's pick. The overlap value of
  Start is the PO's too (item 18).
- **Copy:** the one new line („Nur die Zeit, ohne Tee" / „Just the time, no
  tea") is used word for word once approved.
- **Detekt limits and the combined check:** see `PROJECT_STATE.md` „Session
  facts"; run the check on the merged head before every push.

## Verification (orchestrator, per ticket; as agreed since v0.6.1)

1. The orchestrator reads the diff itself (no behaviour change, copy word
   for word, timer modules untouched unless the ticket says so).
2. Locally: the touched modules' tests and goldens, and the cross-module
   check `spotlessCheck detekt :app:assembleDebug
   :app:assembleDebugAndroidTest :app:compileDebugUnitTestKotlin` on the
   merged head.
3. Push; **CI on the milestone PR is the full gate**. Check its result
   before the next merge builds on that head.
4. The full local gate once more on the rc commit.

For the audit: the orchestrator opens every committed picture and checks
that „after" shows the proposal the text describes, and that `git diff main`
touches only `docs/**`.
