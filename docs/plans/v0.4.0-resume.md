## 3. Environment setup (every new container)

The SessionStart hook installs the Android SDK. Then:

```bash
# Kotlin compiles in-process (two daemons ran the container out of memory in v0.3.0):
mkdir -p ~/.gradle && grep -q in-process ~/.gradle/gradle.properties 2>/dev/null \
  || echo "kotlin.compiler.execution.strategy=in-process" >> ~/.gradle/gradle.properties
```

Create two helper scripts in the session scratchpad (not the repo):

`gw.sh` — every Gradle call, by the orchestrator **and** every implementer, goes through it:

```bash
#!/bin/bash
# Runs ./gradlew in the current directory under a machine-wide lock: one Gradle build at a time (memory).
export ANDROID_HOME=${ANDROID_HOME:-/opt/android-sdk}
exec flock /tmp/umamit-gradle.lock ./gradlew "$@"
```

`gate.sh` — the full local gate on the main checkout, in sequential parts, retrying a part once on exit 137. Replace
`<repo>` with the session's primary working directory: the checkout path differs between containers
(`/home/user/UmamiT` before, `/home/user/UmamiTea` on 2026-11-02).

```bash
#!/bin/bash
cd <repo> || exit 1
SP=<scratchpad>
for part in "spotlessCheck detekt checkManifestPermissions" "--max-workers=1 testDebugUnitTest" \
            "--max-workers=1 lint" "--max-workers=1 verifyRoborazziDebug" "assembleDebugAndroidTest"; do
  for try in 1 2; do $SP/gw.sh $part > $SP/gate-part.log 2>&1; rc=$?; [ $rc -ne 137 ] && break; done
  echo "$part => $rc"
  if [ $rc -ne 0 ]; then grep -E "FAILED|error:|e: |What went wrong" -A3 $SP/gate-part.log | head -40; exit $rc; fi
done
echo GATE PASS
```

- Run the gate in the background with the **maximum timeout (7 200 000 ms)**: behind the shared lock it takes 1–2 h,
  and a 1 h limit killed it once.
- **Never** `pkill java` (it kills the implementers' daemons) and never delete `/tmp/robolectric-*`.
- Disk is a fixed allowance: remove finished worktrees (`git worktree remove --force --force <path>`, then delete the
  `worktree-agent-*` branch).
